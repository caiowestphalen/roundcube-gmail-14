# UI refinement audit — 2026-09-11

This audit refined the existing Gmail-inspired interface, including pages, controls,
menus, dialogs, open/closed states and scrolling in light and dark mode.

## Implemented fixes

| Area              | Root cause and resulting behavior                                                                                                                                                            |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avatar initials   | Avatar was nested inside a text wrapper; it is now a direct grid child with explicit centering. Text centers are measured across responsive widths.                                          |
| Mail layout       | CSS/classes disagreed on tablet breakpoints. Drawer boundary is 1024px; rows adapt to actual pane width, with readable two-line narrow rows and stable hover actions.                        |
| Mobile selection  | Checkbox clicks triggered content navigation. Selection now preserves the list and exposes a bulk-action toolbar.                                                                            |
| Copy/Move         | Core supplied zero root padding. Folder rows use 16px base padding plus 16px per depth, with consistent icon gaps and submenu positioning.                                                   |
| Labels            | Plugin inline markup missed shared menu rules. Full-width rows, complete hover backgrounds and readable light/dark colors now apply.                                                         |
| Confirmation      | Modal teardown resolved cancellation before the clicked result. Result settlement now precedes cleanup.                                                                                      |
| Draft safety      | Empty initial hash bypassed dirty checks; save closed prematurely. Cancel/Discard/Save now work, and failed/timed-out saves retain the editor.                                               |
| Conditional forms | Custom selects ignored backing-field visibility/disabled changes. Wrappers now follow those changes and disabled optgroups.                                                                  |
| Nested controls   | Portalled dropdown clicks/Escape closed parent overlays. Events now stay within the active control; long options wrap within viewport bounds.                                                |
| Multi-select      | Native listboxes remained exposed. Accessible toggle rows preserve selected values, form submission and keyboard behavior.                                                                   |
| Recipient picker  | Invalid addressbook route and wrong frame ownership. Reuses core's existing picker in its compose frame, explicitly targets To/Cc/Bcc, and synchronizes recipient chips.                     |
| Contact photos    | Unsupported closing custom form tag caused nested-form corruption. Valid closing tags keep upload separate; real upload, replace and remove controls work. Login form closure corrected too. |
| Editor            | Dialog surfaces, fields, footer, close/upload/lock icons and theme colors now match the skin; icon controls retain readable 40px targets.                                                    |
| Spellcheck        | Empty/disabled language menu now uses core's language list and updates the selected language.                                                                                                |
| Settings          | Narrow forms, composite contacts, scheduled table overflow, 2FA setup/recovery controls, filter flag/modifier spacing and scroll backgrounds refined.                                        |
| AI summary        | Hidden scripts and action labels leaked into subject text. Summary subjects now contain the message subject only.                                                                            |
| Shared details    | Settings/close icons, task-specific empty states, missing legacy background asset, header spacing and closed-drawer shadow corrected.                                                        |

## Coverage

The recorded review covered 31 routes across mail, composition, contacts and settings,
including plugin pages where installed. Expanded captures covered 390, 820 and 1440px
in both themes. Additional checks covered nested menus, editor dialogs, conditional
filters, contact photo controls, recipient insertion and login layouts.

Public examples in [the README](../README.md#screenshots) contain fictional demonstration
mail and contacts. Raw browser artifacts are local diagnostics and are not published.

## Functional verification

- PASS: 48 `probe-refine.mjs` checks, including eight widths in both themes, avatar center geometry,
  folder picker padding, confirm/prompt outcomes, touch selection/open/back, framed layouts,
  failed-save preservation and successful draft persistence. No browser exceptions.
- PASS: six `probe-mail-refine.mjs` workflows: send attachment, receive and download exact bytes,
  popup reply delivery, apply/clear labels, copy/move/restore, search/thread/print.
- PASS: 12 `probe-extras.mjs` checks: real form serialization/keyboard/disabled state,
  popup Cc recipient targeting, scheduled phone width, spell language and eight login variants.
- PASS: nine deep interaction groups per theme/width, no document overflow or browser exceptions.
- PASS: six label contrast checks, each measuring all six menu rows at a minimum 4.5:1 ratio.
- PASS: build, lint, icon subset and Roundcube core contracts.

## Limits

- A reported small white mark below Inbox could not be reproduced in expanded, collapsed,
  hover or desktop rail states. It is not claimed fixed.
- Identity switching needs verification with a second configured switchable identity.
- Live AI providers, external CardDAV connectivity and saved two-factor enrollment require
  separate integration checks. Their available interface states were reviewed.
- These results describe the recorded audit, not every installation or plugin combination.
